# DNS Party Icon Pack

A lightweight SVG icon set for the DNS Party Windows UI concept.

- Format: SVG (24×24 viewBox)
- Default stroke: #A78BFA (violet)
- Style: rounded outline
- Icons: app-logo, home, star, plus, settings, info, server, check, more-vertical, flush, disable, test, edit, trash, wifi, volume, cloud, power

SVG files can be recolored by changing the `stroke` value. They are scalable and suitable for desktop UI prototypes.
