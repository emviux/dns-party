DNS Party — Logo Asset Pack

Contents
- dns-party.ico: multi-resolution Windows icon (16–256 px), suitable for .exe / shortcut / installer icon.
- dns-party-16.png through dns-party-1024.png: square transparent PNG sizes.
- dns-party-master-transparent.png: transparent master artwork, cropped to the logo bounds.
- dns-party-preview-dark.jpg / .webp: preview on a dark background.

Suggested usage
- Windows executable / installer: dns-party.ico
- Windows taskbar / shortcut: 32, 48, 64, or 256 px PNG as supported by your framework
- System tray: 16, 20, 24, or 32 px PNG (prefer a simplified monochrome tray glyph in production if needed)
- App UI / splash / README: 512 or 1024 px PNG
- Web assets: WebP preview or transparent PNG

Notes
- PNG assets have transparent backgrounds.
- The ICO contains multiple embedded sizes.
- For a crisp native Windows tray icon, consider creating a dedicated simplified 1-color variant.
