# DNS Party — مدیریت DNS ویندوز

**DNS Party** یک ابزار سبک، سریع و با الهام از محیط گیمینگ برای ویندوز است که مدیریت، تست و تغییر تنظیمات سرورهای DNS نسخه IPv4 و IPv6 را تنها با یک کلیک از طریق System Tray برای شما فراهم می‌کند.

---

## روش‌های نصب و استفاده

### گزینه ۱: نسخه پرتابل (بدون نیاز به نصب)
فایل `dist/DNSParty-Portable.exe` را مستقیماً اجرا کنید، یا فایل `dist/DNSParty-Portable.zip` را در هر مکانی از سیستم خود استخراج و استفاده کنید.

### گزینه ۲: نسخه نصبی (Installer)
فایل `dist/DNSParty-Setup.exe` را اجرا کنید تا برنامه نصب شود. این نسخه برنامه را نصب کرده، میانبرهای لازم را ایجاد می‌کند و از طریق سیستم ویندوز قابل حذف است.

---

## ویژگی‌های کلیدی
- **تغییر سریع DNS:** جابجایی سریع بین سرویس‌دهنده‌های معروف (مثل Cloudflare, Google, Quad9, AdGuard) و DNSهای اختصاصی.
- **تست تأخیر (Latency):** اندازه‌گیری و نمایش زمان پاسخگویی سرورهای DNS.
- **بازگشت به حالت خودکار (DHCP):** غیرفعال کردن DNS و بازگشت به تنظیمات پیش‌فرض ویندوز.
- **پشتیبانی کامل از System Tray:** اجرای سبک در پس‌زمینه و دسترسی سریع از طریق نوار وظیفه ویندوز.
